# Add an app-owned feature

ShipAngular no longer publishes a copied module catalog. Generate features directly into
the consuming application's source tree so its compiler, lint, tests, ownership, and
upgrade history all remain explicit.

## Create the feature

```bash
pnpm exec ng generate @sixthsummit/ship-angular:module <name>
```

This creates an app-owned feature under `src/app/modules/<name>/` with standalone routes,
components, and tests. Use the `:page` schematic for additional pages.

## Conventions

- standalone components with `ChangeDetectionStrategy.OnPush`;
- `inject()` for dependency injection;
- signals at public reactive boundaries;
- typed reactive forms;
- `@if`, `@for`, `@switch`, and `@defer` rather than structural directives;
- every route guarded or explicitly marked public;
- colocated `*.test.ts` tests that verify one behavior each;
- no server functions, secrets, database types, or provider-admin SDKs.

ShipAPI-backed data uses the packed contract and `/operations` APIs. Third-party REST is
independent. Capability-specific work uses `/upload`, `/download`, `/stream`, or `/socket`.

## Verify

- `pnpm lint`
- `pnpm type-check`
- `pnpm test`
- feature-specific browser tests for user-observable flows

Do not add a repository-root `modules/<name>`, package-copy hooks, or a new framework
runtime dependency for application-specific UI. The app-owned `module.json` generated by
the schematic is feature metadata, not a publishable framework catalog.
