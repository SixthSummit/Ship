Initial release of `@sixthsummit/ship-storage`: `defineStorageModule` mounts `ship-storage` with signed upload intents (`ship-storage.create-intent`), an actor-bound, provider-verified completion that is atomically fenced against the sweep (`ship-storage.complete`), the `ship-storage.sweep` single-runner job for abandoned intents and never-attached uploads, the `ship-storage.purge` outbox whose intents are recorded inside the consumer's write transaction by `detach()` and kept idempotent by a purge-ledger row, and the lazy `ship-storage.generate-variant` job backed by an injected `ImageProcessor` (`createSharpImageProcessor`) and the cache capability. Adapters: local disk with HMAC-signed URLs served by `createDiskStorageHandler` (`./disk`), S3-compatible with in-house Signature Version 4 over Web Crypto for AWS S3, Cloudflare R2 and MinIO (`./s3`), and Google Cloud Storage over an injected client (`./gcs`); `./hono` provides the HTTP transports.
