ShipAPI is a transport-independent TypeScript application kernel. Operations
declare stable identity, schemas, statuses, errors, access, transactions,
dependencies, effects, and transport together. The compiler turns that code into
one immutable graph.

```ts
const health = defineOperation({
  id: "system.health",
  transport: http.get("/health"),
  input: {},
  output: { 200: z.object({ ok: z.literal(true) }) },
  successStatus: 200,
  errors: [],
  access: publicAccess(),
  transaction: "none",
  dependencies: {},
  handler: async () => ({ ok: true as const }),
});
```

## Release status

Stable kernel and compatibility packages are released from `main`; `dev`
publishes alpha snapshots. See the versioned package changelogs and release
instructions. Synthetic packed consumers and joint conformance fixtures verify
framework boundaries; application deployment is a separate decision.

The monolithic `@sixthsummit/ship-api` package, route-first Hono APIs,
`hc<typeof app>()`, base services, generators, and existing production features
remain documented as compatibility surfaces during the v4 migration window.
