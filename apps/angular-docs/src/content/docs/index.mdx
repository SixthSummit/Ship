## Why ShipAngular

<CardGrid stagger>
  <Card title="Idiomatic Angular 20" icon="seti:angular">
    Standalone components, signals, `inject()`, OnPush, functional guards, typed forms, new control flow only. ESLint custom rules enforce every convention.
  </Card>

<Card title="Frontend-only on purpose" icon="puzzle">
  Pairs with **ShipAPI** for the backend. Use ShipAngular alone against any REST API, or together
  for a full-stack TypeScript-RPC story.
</Card>

<Card title="Agent-first" icon="rocket">
  Ships `AGENTS.md`, `CLAUDE.md`, `.cursor/rules/`, schematics, and an agent eval harness. Built to
  be edited by Claude Code, Cursor, Cline, Aider.
</Card>

  <Card title="Production-grade defaults" icon="approve-check">
    SSR + hydration, zoneless, Tailwind v4, Vitest, Playwright + axe a11y gate, CSP + Trusted Types, Cloud Run-ready Dockerfile.
  </Card>
</CardGrid>

## Get going

Stable versions are released from `main`; `dev` publishes alpha snapshots.
Follow [Installation](/getting-started/installation/) to install public npm packages
and select an exact released version, or build the repository for a local scaffold.

Open [Quick Start](/getting-started/quick-start/) for the five-minute walkthrough or [Installation](/getting-started/installation/) for `ng add` and manual paths.
